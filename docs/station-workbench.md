# 中转站工作分组

中转站继续保存原资料；工作分组通过稳定 ID 关联资料、待办和笔记，同一内容可属于多个分组。现有 `workspaces.json` 工作现场数据直接沿用，新增字段都有默认值，旧记录不需要重新建立。旧版数据在内存中迁移到第 2 版格式，首次实际修改时保存并保留 `.bak`；旧程序遇到第 2 版数据会停止写入，避免回退时丢弃新字段。保存沿用原子替换及 `.bak` 备份。

## 使用

- 单击卡片内容选择，Ctrl 增减，Shift 连选，Ctrl+A 选择当前结果，Esc 清除。编辑框和模态对话框保留自己的键盘行为。
- 选中后出现批量分组、复制、归档、移除与取消操作。点击按钮不会选中卡片；拖动已选卡片会输出整批内容。
- 设置 → 中转站 → 项目操作：六宫格或精简模式。文件／图片、链接、文字分别配置常驻操作（最多三个）；可拖动排序，也可用前移／后移按钮。精简模式始终保留更多菜单，卡片也提供右键菜单。
- 文件支持打开、所在文件夹、复制、路径、加入分组、移除，以及右键重新定位原文件。链接可以编辑显示名称；文字可以查看或编辑。
- 顶部下拉选择全部、未分组或具体分组。新建按钮可将当前选中资料放进新组；分组菜单提供名称说明、置顶、排序、解散和归档导入。
- 独立窗口左侧显示类型分类和我的分组，支持直接拖入分组。分组资料页可继续按类型、时间和搜索筛选。
- 分组中提供资料、待办、笔记页。可以建立或关联已有任务／笔记，修改与原入口同步，任务还可关联具体资料。
- 待办与笔记显示所属分组链接，可返回分组。任务可启动专注；时钟可返回关联任务。替换运行中的计时需要确认，计时结束不自动勾选任务。
- 结束专注可写接续记录，分组显示最近非空进度和累计用时，任务显示专注次数及最近时间。

## 移除与归档

分组内移除仅解除该分组中的关联；全部资料中移除会移除中转站记录，不删除磁盘原文件。解散分组保留资料、任务、笔记及专注历史。失效引用不能被归档过程静默略过。

选中项目时归档所选资料；进入具体分组且没有选中项目时，右上角归档会复制整个分组，包含资料文件、链接／文字、笔记图片、任务、进度、专注记录及任务资料关联。整组归档完成后保留当前分组。

归档以 `未完成_` 目录开始，资料复制进行 SHA-256 校验，全部清单完成后才改成正式工作分组目录。取消或失败不能当成完成的分组导入。普通资料归档沿用原有“归档后移出”选项。

导入选择含 `workspace.json` 的完整分组目录。验证路径范围、重解析点和文件校验和，将附件复制到本机，再创建新的关联 ID；重名分组自动避让。任务提醒保持关闭。导入失败尽量回滚本次新增记录；若回滚遇到写入故障，保留本次导入目录供恢复，避免误删仍被引用的附件。突然断电时跨多个数据文件的提交不保证整体原子性，原有数据不被覆盖。

批量拖出混合资料时，链接输出为 URL、文字输出为 TXT；Windows 对 URL 快捷方式的普通 StorageFile 访问有限制，因此 URL 通过原生流式虚拟文件传递。接收方是否支持虚拟文件由目标软件决定。转换副本保存在本机的中转站附件目录。

## 验证范围

`tests/WorkbenchChecks` 覆盖布局设置持久化、关联身份、多入口共享记录、专注进度、完整分组归档／导入、重名、容量失败回滚、文件损坏和路径越界。

`--verify-workbench --data-dir <隔离目录>` 检查原生卡片、范围选择、批量数据包、六宫格／精简配置、分组页及独立窗口导航。现有中转站、待办、时钟、工作流程、尺寸及界面风格检查继续运行。实际资源管理器或其他第三方软件的拖放接收兼容性不能由数据包测试代替。
