# 留白中转站设计规范 1.0

状态：默认设计基线。整理日期：2026-11-08。

后续中转站改动默认遵循本文，用户明确的新要求优先。通用参数继承[留白视觉规范](visual-language.md)，操作细节见[操作与导航](station-controls.md)。已确定规则与待实施规划分开维护。

## 1. 视觉与组件

- 沿用玻璃材质、柔和取色背景、圆角卡片、细线矢量图标和白色细边框。明暗、高对比、焦点、悬停、按下、禁用和选中状态使用公共组件与原生模板。
- 参数来自 `Theme.xaml`、`PanelTheme` 和用户界面风格设置，避免各入口独立复制。危险操作悬停提示红色；图标提供名称提示及可访问名称。
- 工程参考值均为逻辑像素：预览 48；图标 16／20／24；图标按钮点击区域 36，大图标 40；中转站卡片基础内边距横向 12、纵向 7。按缩放和用户疏密设置调整，不靠缩字增加密度。
- 动效轻短并遵循系统动画设置；状态变化避免闪烁、整页重载或无故跳动。

## 2. 布局

| 范围 | 停靠／缩小版 | 独立／展开版 |
|---|---|---|
| 用途 | 快速存取 | 浏览、选择、整理 |
| 标题 | 中转站及总数量 | 中转站或中转站·当前分类／分组，不显示总数 |
| 顶部 | 第一行标题与全局操作；第二行分组、新建、导入 | 单行主工具栏，左侧项目操作、右侧全局操作 |
| 项目操作 | 卡片六宫格或可配置精简布局，多选后底部批量栏 | 顶部公共操作栏，卡片不重复铺按钮 |
| 导航 | 横向滚动分组标签及省略号 | 宽窗口左侧分类和分组，窄窗口保留分类入口 |

展开版顺序：标题 → 打开、复制、所在文件夹、详情／编辑、加入分组、移除 → 整组资料拖出、“资料／待办／笔记”文字菜单 → 弹性空白 → 细竖线 → 时间、新建、导入、搜索、清空、归档及窗口控制。

竖线短、细、低对比，靠近右侧操作区。长标题省略并可悬停查看。宽度不足时分别收纳项目与全局操作，不缩小点击区域、不挤出第二行。切换待办／笔记隐藏文件专用操作。标题与可用空白支持原生拖动，按钮不落入拖动区域。

## 3. 内容与导航

- 卡片左侧缩略图，右侧名称和时间，不另列类型。名称最多两行，悬停查看全名；链接域名并入时间行；异常按需显示并提供完整提示。六宫格按按钮高度撑开，不裁切操作区。
- 全部、图片、文件等分类始终面向整个中转站；切换时退出分组或未分组，回到资料页并清除选择，时间筛选保留。“查看全部”同时清除时间筛选。
- 进入分组仅显示该组内容，类型回到全部。标题、高亮、列表、搜索和清空／归档范围保持一致；侧栏与窄窗口共用导航规则。
- 分组标签保持顺序，滚轮浏览不改变选择；省略号保留未完整显示的分组及管理入口。

## 4. 选择、菜单与拖放

- 单击选择、Ctrl 增减、Shift 连选、Ctrl+A 选择当前结果；展开版双击打开。多选按展示顺序计算范围，不意外批量打开文件。
- 窗口内空白或非输入区 Esc 清除选择，窗口保持打开；只更新边框、计数和操作状态，保留范围、卡片及滚动位置。卡片、控件、输入、菜单、滚动及拖动不触发空白取消。
- 操作按数量、类型和只读状态启用，无选择时公共项目操作禁用；右键保留完整适用操作。
- 加入分组支持按钮悬停／点击，更多及右键使用二级菜单。列表可滚动、标识已有关系；点击直接加入缺少的关联，保留选择和撤销。仅新建分组时弹出名称输入框。
- 菜单保护本次操作目标与面板可见性，跨越按钮和菜单不立即关闭，移开延迟关闭；支持键盘、触控和 Esc，关闭后不应立即反复弹出。
- 拖入成功保持面板可见并反馈；拖出请求复制，记录保留。虚拟附件和跨软件接收边界见[工作分组说明](station-workbench.md)。

## 5. 搜索、窗口与反馈

- 顶部统一搜索在同一窗口内展开，可选当前范围或全部内容，不新增常驻资料搜索行。叉号／Esc 返回原页，保留选择和双向浏览位置；外部收起不自动弹回。
- 停靠与独立窗口分别记忆尺寸，调整时 Esc 可取消。固定、入口再次点击关闭及外部收起沿用公共面板生命周期，独立窗口可正常移动。
- 自动保存与显式保存如实反馈。静态说明集中在“设置 → 帮助 → 中转站”；内容区仅保留必要状态、结果、错误、进度与撤销。加载警告和进行中的任务不按普通短提示清除。

## 6. 数据与性能

- 清空、移除记录或解散分组不删除原文件；分组以稳定引用关联资料、待办和笔记，浏览切换不修改关联。
- 清空、归档及批量操作明确作用范围，危险确认采用安全默认值。归档校验、取消、导入与恢复边界沿用工作分组说明。
- 缩略图异步并限制并发、缓存及解码；收起取消任务、释放视图。布局变化尽量复用内容，避免因选择、滚动重新读取文件；视觉调整不改变记录和提醒规则。

## 7. 验收与维护

按影响检查：停靠／展开／窄窗口；选择与空白取消；分类和分组互相切换；菜单、页面与搜索返回；拖放、窗口拖动和尺寸；明暗、缩放和外观设置；操作范围、保存与异常反馈。跨功能或数据安全改动补充针对性回归，文档修改无需构建或重启。

主规范维护约束，用户帮助讲操作，技术文档讲实现与验证边界；变更时同步直接相关说明，不把历史布局当成现行规则。细节：[输入弹窗](entry-dialogs.md)、[撤销／预览／搜索](station-experience.md)、[功能生命周期](feature-lifecycle.md)。

## 8. 待实施规划（尚未启用）

展开版资料卡片自适应每行 1～3 项，停靠版单列。实施时按内容区逻辑宽度计算，时间标题独占整行；保留排列顺序、选择和可见项目锚点，不重复加载缩略图。当前仍为单列，本次规范整理不实施此功能。
