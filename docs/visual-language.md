# 留白视觉规范 1.0

方向：轻透、圆润、克制。保留 Windows 原生键盘、焦点、禁用和高对比状态；功能面板使用同一套外壳、标题栏、图标按钮和卡片。

## 参数入口

`src/Liubai/Theme.xaml` 是开发者使用的基础主题资源字典。用户可在“设置 → 界面风格”中实时调整主要参数，不需要重新编译。所有尺寸为 Windows 逻辑像素，随系统缩放。

## 用户设置

界面风格独立保存在用户数据目录的 `ui-style.json`，含版本号、参数范围校验、原子写入和备份。遇到未来版本或无法恢复的配置时保留原文件并停止写入。

- 预设：默认轻透、柔和圆润、紧凑清爽、自定义。手动细调自动转为自定义。
- 圆角程度：0–20，作为按钮及输入框圆角，卡片为其 1.5 倍，XAML 面板背景为其 2 倍。原生窗口轮廓仍由系统管理。
- 疏密：紧凑、标准、宽松，调整面板边距、分区间距与卡片留白。
- 图标：16、20、24 逻辑像素；点击区域至少 36，大图标为 40。顶栏图标不随此项改变。
- 材质：面板染色浓度和明暗遮罩各 0–100%，跟随系统明暗；与顶栏材质独立。
- 动画：关闭或轻柔，打开时长 100–300 ms。系统关闭动画时直接显示。

修改会即时更新已有面板，约 400 ms 停止调节后保存；收起设置、右上角保存和底部“确定保存”都会补保存。恢复默认风格仅恢复本节参数。材质复用原控制器，AI 复用原 WebView，对话与网页不重载。运行时注册使用弱引用，销毁的窗口退出更新列表。

## 组件约定

`PanelTheme` 提供 Layout、Header、Actions、Title、Hint、Glyph、Icon、Card 和 Backdrop。新功能优先使用这些工厂，不再复制尺寸和颜色常量。

- 标题栏：左侧标题或页签，右侧操作；可伸缩的标题区域与按钮区域分列。独立窗口的原生拖动区域始终排除按钮。
- 图标按钮：默认透明；原生模板处理悬停、按下、禁用、焦点。固定按钮用原生 ToggleButton 保留选中反馈。每个按钮有无障碍名称和悬停说明。
- 中转站项操作：打开、复制、移除顺序不变，使用统一的浅色细边框。深色环境降低边框亮度；高对比环境采用系统配色。
- 卡片：默认背景与边框跟随实际主题动态更新。中转站保留从图片提取的渐变，缩略图和正文仍然优先保证辨识度。
- 输入和菜单：继续使用 WinUI 原生模板，统一控件圆角，避免破坏输入法、日历、下拉框和键盘导航。
- 材质：功能面板使用独立统一的玻璃参数；顶栏的用户材质、无基底模式和窗口跟色不受影响。系统决定是否降级为不透明底色。

## 动效与生命周期

`PanelMotion` 只在面板由隐藏变为可见时播放一次短淡入和小幅位移。固定、重复激活、接收拖放、刷新列表不会重新播放。收起立即隐藏并清理动画，不延迟失焦收起、第二次点击关闭或保存流程。系统关闭动画时直接显示。

动效不创建长期计时器，不截图，不重载 WebView，不更改数据格式。原生窗口位置、尺寸记忆、Esc 取消拖动及固定语义保持原有实现。

## 后续扩展

先调整主题参数，再调整公共组件；只有功能本身的结构变化才修改具体面板。用户风格选项经过范围校验，不允许任意资源或样式覆盖权限和功能逻辑。

检查重点：中转站最窄尺寸、放大/停靠、标题栏拖动、深浅主题切换、图标禁用与固定状态、键盘焦点、Esc、连续打开收起、保存及拖放。没有实测的系统缩放和高对比组合不能声称已验证。
