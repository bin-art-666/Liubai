# 顶栏布局与更多工具

设置中的“顶栏布局”管理入口位置、图标间距、排序和分组留白。默认保留原来的全部入口，未使用此设置时不创建额外布局文件。

| 位置 | 行为 |
| --- | --- |
| 顶栏 | 按已保存的顺序显示，宽度不足时临时收进更多 |
| 更多 | 显示在更多工具面板中 |
| 隐藏 | 顶栏及更多均不显示，可在设置恢复 |

设置入口始终保留，顶栏低于 24 时沿用托盘打开设置的方式。设置中也提供“打开更多工具”，方便极窄或低高度顶栏使用。隐藏入口不是禁用功能，已有计时、提醒、守护等运行状态不因此改变。

## 排列与宽度

- 顺序沿用外观配置中的 `ToolbarOrder`，兼容已有 Ctrl 拖动排序。
- 顶栏的 Ctrl 排序按可见入口定位，保留未显示项目的相对顺序；更多与隐藏项通过设置中的上下箭头调整。
- 间距为 0–16 逻辑像素；紧凑、标准、宽松分别为 0、2、8。分组是在指定入口前增加留白，不新增功能图标。
- 每块屏幕按自己的可用宽度计算溢出，计时数字和专注标题占用的宽度也参与计算。优先保留设置入口；宽度恢复后，临时溢出的工具回到顶栏。
- 自动溢出不写回用户选定的位置，因此屏幕缩放、换屏或开始计时不会永久改变布局。

## 更多面板

沿用公共玻璃面板、标题栏、收起与 Esc 逻辑。再次点击更多图标可收起；拖动内容悬停更多图标可展开，再拖到具体工具。

复用现有工具按钮及其点击、右键和拖入行为。展开时暂时迁入面板，收起时恢复原图标内容、布局和父级。更多负责工具，中转站负责内容。更多内的 Ctrl 排序和长按预览不启用，避免与顶栏手势冲突。

WinUI 的弹出菜单不能在设置 XamlRoot 后迁往另一个窗口。顶栏与更多分别持有菜单实例，通过同一工厂创建相同命令和状态逻辑，工具返回顶栏时恢复原菜单。带实际 ToolTip 控件的入口也使用独立的临时提示，防止跨窗口根复用。

## 保存与恢复

`toolbar-layout.json` 单独保存入口位置、分组和间距，使用版本校验、参数校验、原子写入及备份。改变后立即预览，约 400 ms 后自动保存；收起设置及保存全部设置时补保存。未来版本或无法恢复的数据保留原文件并停止写入。

恢复默认布局重置入口位置、间距、分组及排序，不改变顶栏材质、界面风格或功能数据。本轮只实现入口组织，功能禁用、模块生命周期统一、应用更新和扩展接口属于后续阶段。
