# 撤销、快速预览与统一搜索

三项功能沿用中转站材质、圆角、图标及面板生命周期，没有新增顶栏工具图标。

## 撤销

移除单项／多项、清空记录、移出分组、解散分组、加入分组及归档后移出记录，会产生会话内的逆操作。面板底部短暂显示处理结果与撤销按钮；提示收起后仍可按 Ctrl+Z，或从分组操作菜单选择“撤销上次操作”。

撤销保留原记录 ID，恢复相关分组与任务资料关联，合并而不是覆盖后来新增的任务、笔记或其他关联。恢复前校验当前状态；重名分组、已重新存入的相同资料或其他冲突不会被强行覆盖。恢复涉及两个存储时先验证，再写入；第二步失败时尝试回滚第一步。

只恢复记录和关联，不移动或删除磁盘文件，也不会删除已经生成的归档。文字输入框使用自身撤销，Ctrl+Shift+Z 不触发此功能。待办／随手记原有编辑撤销不受影响。

历史不跨重启，最多保留最近 10 次操作，单次估算上限 16 MiB、总估算上限 32 MiB。超出单次上限会明确提示并清空会话历史，避免 Ctrl+Z 意外作用于更早操作。引用大小用长度估算，不序列化整批内容制造额外内存峰值。

## 空格快速预览

选择一张资料卡片后按空格，在当前面板内打开预览；再次空格或 Esc 收起。图片按需解码，最长边最多 1200 像素，处理 EXIF 方向与颜色空间；超过 64 MiB 的图片使用系统缩略图路径。文本文件最多读 20,000 字符，支持 BOM；链接和文字只展示本地内容，不自动访问网页。文件夹最多列出 40 项，不递归。

PDF 在 16 MiB 以内时使用 Windows 原生接口渲染首页，先读取有大小限制的内存快照，避免 PDF 引擎持续占用原文件；不创建浏览器。其他文档或无法渲染的 PDF 显示 Windows 缩略图或文件信息，文件图标保持小尺寸，不放大冒充内容预览。用户点击“用默认程序打开”后才启动外部软件。

读取设置取消与超时，收起、切换资料、记录失效或关闭窗口时清除界面引用和读取任务，不保留专门的预览服务或网页环境。

## 统一搜索

入口在中转站标题栏的搜索按钮；非输入区可按 Ctrl+F。搜索资料、分组、待办和笔记，包括本地记录的路径、链接、正文及所属分组名称。多个词按全部匹配，标题精确匹配优先，其后按更新时间排序，最多显示 100 项。

输入有短暂防抖，匹配在后台进行，新输入取消旧任务；计算期间不能激活旧结果。来源变化会刷新结果。点击资料会定位并选中中转站原记录，点击分组、待办或笔记返回对应入口；不复制数据或自动打开外部链接。

不扫描磁盘、不上传内容、不记录搜索词。只在打开面板时订阅数据变化，收起后取消任务、清空结果、解除订阅。与其他面板一起响应切换、睡眠、显示器移除和退出。

## 验证

核心检查包含逆操作合并、冲突保护、十步上限、保留后续任务、预览字符上限与取消、跨类型搜索、正文匹配和结果数量上限。原生模式 `--verify-station-experience` 使用隔离数据验证实际控件、Windows 图片解码、撤销反馈、动态搜索及结果定位。
