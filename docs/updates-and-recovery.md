# 版本、更新与恢复（第三阶段）

入口：设置 → 版本、更新与恢复。显示程序集版本和本机构建时间、检查更新、更新说明、下载更新并重启、回退上一版本，以及维护目录和本机数据／日志目录入口。沿用公共玻璃面板和原生控件。

## 检查与下载

- 只由用户手动检查，不开机联网，不定时检查，不自动下载或重启。
- 读取 `bin-art-666/Liubai` 的 GitHub 最新正式 Release。排除草稿、预览版本；只接受严格正式版本号及 `Liubai-{tag}-win-x64.zip`，来源和 SHA-256 必须匹配。
- 版本号相同或更旧时不能安装，避免 GitHub 旧包覆盖本机尚未发布的改动。版本升级时需正常提高项目版本号再发布。
- 下载允许取消，限制大小和重定向来源，逐块写入磁盘。安装前校验实际长度和 SHA-256；解压前拒绝路径穿越、大小写重名、链接、Windows 保留名称和不完整程序包。
- 检查失败、离线、限流、取消、校验失败均保留当前程序。程序目录不可写时不申请管理员权限，可通过发布页手动下载。磁盘根目录安装保持设置可用，但不提供原地更新。

## 保存、安装与重启

用户确认 → 下载和校验 → 保存全部面板 → 暂停并排空提醒调度 → 备份顶层 JSON 与 `.json.bak` → 启动隐藏维护助手 → 助手就绪 → 提交安装 → 正常退出 → 助手等待原进程结束 → 重新核验核心文件 → 交换目录 → 启动新版 → 确认启动。

运行或暂停中的计时／闹钟、文件导入／归档、其他模态面板及未保存内容会阻止重启。不会为升级取消计时；用户需先处理它们。保存校验失败会返回失败并停留当前界面，而不是只显示错误后继续退出。

安装助手在当前用户下运行，临时暂停已有的留白自启任务，结束后恢复其原启用状态；原来未开启自启的用户不会因此启用。程序路径保持不变。助手不强制结束程序；缺少父进程的提交记录就不会替换。新版进程已经退出或启动失败时恢复原程序；进程仍存活但未确认启动时保留它和回退副本，标记“未确认”，供用户核对。

维护目录位于程序目录旁的 `.liubai-update-{安装路径标识}`，有安装路径归属标记。`previous` 为一份受控的程序回退副本，`previous-settings` 为操作前配置快照，`result.json` 记录结果。此目录不同于散落的开发构建。正常更新完成后清理更早的程序副本；失败恢复不覆盖已有的回退版本。更新中的计划、暂存和就绪记录也位于该目录。

## 数据与恢复边界

回退只交换程序，不覆盖当前用户数据。操作前的 JSON 快照可在维护目录查看；不包含网页登录、外部文件和附件原件。现有配置迁移、原子保存、备份恢复和未知版本只读保护继续生效，本阶段不改变待办／中转站数据格式。回退程序无法理解新格式时停止写入，原数据保留。

正常安装或启动失败可自动恢复；断电或系统强制结束维护助手发生在目录交换中间时，不能保证自动恢复。若程序目录缺失，应先确认程序未运行，再从维护目录中的 `previous` 恢复原完整程序目录；保留 `result.json` 和用户数据，避免只复制 EXE。此版本没有常驻的第二套恢复服务或额外的登录恢复任务。

升级重启关闭 AI 页面，未发送草稿能否恢复由网站决定；摄像头守护重新启动仍默认关闭。单纯检查更新不加载 AI、摄像头或截图资源。

## 验证

- `tests/UpdateChecks`：更新策略、模拟网络响应、限流、取消、同版本拒绝、摘要、解压边界、只读原程序、配置快照与目录归属。
- `tests/UpdateChecks/WorkerChecks.ps1`：使用真实隔离目录交换，仅模拟进程启动和自启任务，覆盖成功、回退、启动异常、提前退出、缺少提交、核心文件被改动和未确认的存活进程。
- `--verify-updates --data-dir <隔离目录>` 检查原生设置、保存失败阻断和启动确认；`--verify-updates-network` 额外只读检查 GitHub，不下载或安装正式包。

接口依据：[GitHub Releases REST API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)。SHA-256 校验用于核对 GitHub 发布附件完整性，不等同于独立的代码签名。

2026-11-06 验证：67 项更新与网络检查、27 项事务检查、85 项原生回归和 4 项真实隔离助手检查通过。真实助手替换隔离目录、启动实际 WinUI 程序并核验 PID 就绪记录，再正常关闭。线上仅检查 GitHub 元数据，同版本发布不覆盖本机代码。首次 TLS 请求失败后复核恢复正常，保持默认完整证书校验，错误写入本机 `update.log`。
