# 顶栏显示方式

入口：设置 → 日常设置与配置 → 顶栏显示方式。更改立即保存，支持配置导入／导出；恢复默认为常驻顶部。个人外观预设不改变此项。

| 模式 | 行为 |
| --- | --- |
| 常驻顶部 | 默认显示并预留工作区，独立于全屏专用外观开关 |
| 自动隐藏 | 不预留工作区，边缘唤出时覆盖显示 |
| 最大化／全屏时隐藏 | 每屏最上层有效窗口最大化或全屏时使用隐藏模式，普通窗口时恢复常驻与工作区 |

隐藏状态下，鼠标连续停留顶部左 1/3 或右 1/3 约 200 ms 唤出，中间 1/3 屏蔽；离开顶栏约 700 ms 收起。边缘高度随 DPI 缩放，多屏独立判断，支持负坐标显示器。系统关闭动画时直接显示。

停靠面板、菜单、预览及拖动排序期间保护显示；独立 AI／中转站窗口不强制保持顶栏。截图框选期间冻结自动判断。锁屏与睡眠停止轮询，恢复后重新判断。手动隐藏优先于边缘唤出，托盘可恢复显示或打开设置；低于 24 px 的顶栏仍需通过托盘设置。

常驻模式不新增轮询；隐藏模式使用 100 ms 指针检查，最大化模式约 300 ms 读取窗口几何并稳定确认，不截屏、不采样颜色。改变最大化状态会相应释放／恢复工作区；单纯唤出、收起不会改变工作区。

验证：`--verify-auto-hide --data-dir <独立目录>` 检查边缘区域与延时、工作区释放、覆盖唤出、设置保存、面板保护、最大化状态接入、手动隐藏及暂停恢复，生成 `auto-hide-check.json`。纯逻辑边界与配置兼容性由 AppearanceChecks 覆盖；多块真实显示器仍需实际设备观察。
