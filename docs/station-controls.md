# 中转站操作与分组导航

默认设计约束见[中转站设计规范 1.0](station-design-spec.md)。本文补充当前操作细节，停靠版和独立窗口的布局分别说明。

分类入口（全部、图片、文件等）始终浏览整个中转站。点击时退出具体分组或未分组、回到资料页并清除项目选择，标题、高亮和操作范围同步更新；时间筛选保留。“查看全部”还会清除时间筛选。窄窗口下拉遵循相同规则，进入分组时不预选全局“全部”，确保可以再次选择返回。切换仅更新浏览状态，不改变分组关联。

独立窗口使用单行主工具栏，标题显示当前分类或分组，取消总数；项目操作在标题之后，选中数量仅在有选择且空间充足时显示。分组提供整组资料拖出和“资料／待办／笔记”文字菜单，取消原来独占一行的下拉框。细竖线靠近右侧全局操作，窄窗口分别通过“所选项目操作”和“中转站操作”收纳；切换待办／笔记时隐藏文件专用操作。停靠版保持原布局。

资料卡片使用紧凑排版：名称最多两行并可悬停查看完整内容，下方显示时间，链接合并显示域名；不再单独显示类型。路径失效时在时间行提示，完整状态可悬停查看。缩略图与原有字体、圆角及取色保留，卡片上下留白和列表间距收紧；停靠版六宫格仍按操作按钮的实际高度排版。

加入分组统一为原生快捷菜单：展开操作栏、停靠批量栏及卡片图标悬停 250ms 或点击打开；卡片更多与右键通过“加入分组”二级菜单选择。列表限制高度并支持滚动，置顶分组优先。菜单打开时冻结本次目标，显示“已加入”或“已有 x/y 项”；点击直接加入缺少的关联，保留当前选择和浏览范围，并可撤销。只有“新建分组并加入…”弹出名称输入框。移出悬停菜单延迟关闭，点击打开的菜单保留原生键盘／触控及外部关闭行为。

停靠版和独立窗口都支持点击列表间隙、列表底部或面板背景取消全部选择，窗口保持打开。只清理选中边框、计数及操作栏状态，不重建卡片或改变分组、筛选、滚动位置。卡片、控件、标题栏、菜单、滚动条及拖放／模态／调整尺寸期间不触发空白取消；Esc 继续可用。

独立窗口采用公共项目操作栏：选中后打开、复制、所在文件夹、详情／编辑、加入分组、移除。多选禁用打开和单项详情，保留批量复制、分组与移除；右键和整组／所选归档继续可用。卡片仅展示内容，双击打开；停靠面板原布局不变。

独立窗口第一行右侧为时间筛选、新建分组、导入归档、搜索、清空、归档、收起、固定、关闭；窄窗口折叠低频操作。时间菜单沿用原时间范围，生效时有圆点标记。取消常驻资料搜索和时间下拉框，顶部搜索页面支持当前分类／分组与全部内容，返回保留列表状态。

停靠版第一行标题旁显示总数量，右侧依次为搜索、清空、归档、放大／还原、固定、关闭。宽度不足时，前三项折叠到“中转站操作”菜单，按钮不缩小；该菜单保留当前范围的名称及禁用状态。窗口原生拖动区域排除整个右侧操作区。

停靠版第二行左侧为分组标签，右侧固定新建与导入。计算标签可用宽度时先预留右侧按钮空间。标签保持既有顺序，鼠标滚轮映射为水平浏览并消费边界滚轮事件；触控板横向滚动也可浏览。省略号固定在滚动区域右侧，按打开时的实际视区列出未完整显示的分组。选中分组后滚入可视区域，不重排标签；右键和省略号支持分组管理。宽独立窗口保留左侧分组导航。

静态介绍、自动保存说明、拖出提示和附件说明集中在“设置 → 帮助 → 中转站”。卡片保留名称、时间及异常状态。操作反馈短暂显示，后台处理期间继续保留；加载警告不会定时隐藏。撤销、归档进度、选择操作和当前筛选下的“查看全部”只在相关状态出现。

帮助按需创建，涵盖存取、分组、多选、预览、搜索、归档、原文件规则及快捷键，不调用网络、不初始化 AI 或摄像头。

搜索复用原窗口及标题栏，在中转站内部切换内容页。叉号为共享白边矢量按钮，含义为返回；Esc 也返回。返回恢复资料和分组滚动位置，保留选择、分组、尺寸、固定与独立窗口状态。外部关闭仅隐藏整个面板，不自动弹回。收起搜索后取消任务、清空结果并解除数据订阅。
