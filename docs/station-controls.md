# 中转站操作与分组导航

第一行标题旁显示总数量，右侧依次为搜索、清空、归档、放大／还原、固定、关闭。宽度不足时，前三项折叠到“中转站操作”菜单，按钮不缩小；该菜单保留当前范围的名称及禁用状态。窗口原生拖动区域排除整个右侧操作区。

第二行左侧为分组标签，右侧固定新建与导入；独立窗口选中分组时还提供整组拖出。计算标签可用宽度时先预留右侧按钮空间。标签保持既有顺序，鼠标滚轮映射为水平浏览并消费边界滚轮事件；触控板横向滚动也可浏览。省略号固定在滚动区域右侧，按打开时的实际视区列出未完整显示的分组。选中分组后滚入可视区域，不重排标签；右键和省略号支持分组管理。宽独立窗口保留左侧分组导航。

静态介绍、自动保存说明、拖出提示和附件说明集中在“设置 → 帮助 → 中转站”。卡片保留名称、类型、时间及异常状态。操作反馈短暂显示，后台处理期间继续保留；加载警告不会定时隐藏。撤销、归档进度、选择操作和当前筛选下的“查看全部”只在相关状态出现。

帮助按需创建，涵盖存取、分组、多选、预览、搜索、归档、原文件规则及快捷键，不调用网络、不初始化 AI 或摄像头。

搜索复用原窗口及标题栏，在中转站内部切换内容页。叉号为共享白边矢量按钮，含义为返回；Esc 也返回。返回恢复资料和分组滚动位置，保留选择、分组、尺寸、固定与独立窗口状态。外部关闭仅隐藏整个面板，不自动弹回。收起搜索后取消任务、清空结果并解除数据订阅。
