# 留白 · 玻璃顶栏

Windows 11 原生顶部栏，集成截图、扫码、时钟、待办、随手记、中转站、屏幕守护、一键隐私、AI 快捷窗与设置；按住 Ctrl 可拖动图标排序。所有图标统一按钮样式、细线风格和明暗配色。中转站可暂存文件位置、文字和链接。默认在所有屏幕顶部显示 36 个逻辑像素，高度可调整为 1–120，也可选择仅主屏。

参考 LumaBar 的低饱和染色与磨砂风格，使用 Windows App SDK 2.6.4、WinUI 3 和 `DesktopAcrylicController` 提供轻透玻璃、柔和磨砂、浓厚亚克力三个原生 Acrylic 预设，以及可实时调节的自定义材质。有基底时使用原生 Acrylic，不自行截屏模拟玻璃；无基底使用直接透明合成与颜色叠加。系统关闭透明效果或启用相关辅助功能时，原生玻璃遵循 Windows 的回退策略。

## 运行

按住 Ctrl，用鼠标左键拖动任一顶栏图标即可预览排序；保持 Ctrl 并在图标区域内松开鼠标，顺序会自动保存。按 Esc、提前松开 Ctrl 或拖到区域外释放会取消。所有屏幕共用顺序，重启和配置导入／导出会保留；恢复默认设置会恢复初始顺序，外观预设不改变排序。拖动排序不会触发图标功能。原生核心验证：`dist\Liubai.exe --verify-toolbar --data-dir <独立目录>`。

从 [Releases](https://github.com/bin-art-666/Liubai/releases) 下载 Windows x64 压缩包，完整解压后双击 `Liubai.exe`；从源码构建时程序位于 `dist\Liubai.exe`。请保留同目录的全部文件，无需另装 .NET。右上角齿轮可打开设置或退出，外观自动保存到 `%LOCALAPPDATA%\Liubai.Bar\appearance.json`。默认不开机启动，可在“日常设置与配置”中开启；只修改当前用户的留白登录任务。

使用 Windows 官方 AppBar 接口分别预留每块屏幕的顶部工作区，断开屏幕、隐藏和退出时释放。默认启用最大化／全屏专用外观，全屏时保持对应屏幕的顶栏显示；关闭专用外观后，全屏隐藏，结束后恢复。

任务栏右下角只保留一个“留白”托盘图标：点击打开设置，右键可打开待办和随手记、显示/隐藏全部顶栏、暂停/恢复颜色跟随、切换材质或退出。隐藏顶栏会释放顶部工作区，再次显示时恢复预留；隐藏期间仍可通过托盘打开设置。Explorer 重启后自动恢复托盘图标。Windows 可能将新图标放在“显示隐藏的图标”区域，可拖到任务栏右下角常驻。

## 一键整屏截图

点击最左侧的相机图标，直接截取按钮所在的整块显示器，包含当时可见的顶栏、任务栏和窗口，不进入框选。保持显示器原始像素尺寸；多屏分别使用各自显示器坐标与边界。

默认复制图片到剪贴板，并保存 PNG 到系统“图片／留白截图”，文件名包含日期与时间。点击后等待按下效果与悬停提示消失，完成后显示简短提示；连续点击会合并，截图过程中退出会等待当前操作结束。复制与文件保存独立处理，某一步失败会按实际结果提示，不把部分失败误报为全部成功。

设置中的“截图设置”可选择是否同时保存文件，以及更改保存目录。截图选项独立保存在 `%LOCALAPPDATA%\Liubai.Bar\screenshot.json`，不随外观预设、配置导入导出或恢复默认外观迁移本机目录。

右键点击相机图标，在与其他顶栏按钮一致的菜单中选择“打开截图文件夹”。打开当前设置的保存目录，目录不存在时自动创建；即使关闭文件保存也可打开该目录，路径失效或没有权限时会提示。

验证：`dist\Liubai.exe --verify-screenshot --data-dir <独立目录>`，检查实际 PNG 分辨率、图像数据包、保存选项、写入失败和重复点击保护。验证不读取或修改系统剪贴板，测试图片仅放在独立目录。

## 框选扫码

点击相机右侧的二维码图标，冻结桌面后拖动框选二维码，松开即可本地识别。按 Esc、右键或“取消”退出；极小选区允许重新拖动。支持在连接的显示器范围内框选，框选图按物理像素裁剪，保留原始清晰度。显示布局变化、锁屏、睡眠或失去焦点时取消框选。虚拟桌面包围矩形最多 3200 万像素，超出时提示，不分配超大截图。

单个 HTTP/HTTPS 网址自动交给 Edge 打开，不改变默认浏览器。多个二维码显示结果列表，由用户选择；文字、Wi-Fi 及其他协议内容只显示和复制，不自动执行。未识别到二维码可直接重新框选；Edge 启动失败时保留结果，支持复制或重试。

使用 ZXing.Net 0.16.11 在本地内存中解码，支持旋转及反色二维码。截图不上传、不落盘，也不读取系统剪贴板；只有手动点击“复制内容”才写入剪贴板。识别不保存历史，不增加常驻截图轮询。第三方库许可见 `ThirdParty`。

验证：`tests/QrChecks` 覆盖中文、网址、Wi-Fi、旋转、反色、多二维码、像素裁剪和网址类型判断；`dist\Liubai.exe --verify-qr --data-dir <独立目录>` 检查真实桌面覆盖层、取消及结果卡片收起。加 `--interactive-qr` 可框选程序生成的测试码完成实际鼠标链路验证，不读取或修改系统剪贴板。

## 时钟 · 闹钟与倒计时

时钟位于待办左侧，共用一个细线表盘图标和玻璃面板；也可以从托盘右键打开。闹钟与计时是两个标签，点击外部或 Esc 收起面板，后台继续计时。图标小圆点表示仍有启用的闹钟或运行／暂停的倒计时，悬停显示剩余时间或下个闹钟。

打开时钟时，优先显示正在运行或暂停的倒计时，没有活动计时则显示闹钟；通知指定的闹钟或计时仍打开对应页面。面板底部可勾选“在顶栏显示剩余时间”，默认关闭；开启后仅在活动倒计时旁显示时间，暂停显示 `Ⅱ`，完成或取消后恢复纯图标。数字使用等宽排版并保留固定空间，避免秒数变化和暂停时顶栏跳动。这个选择独立保存在时钟数据中，不会修改提醒时间。齿轮设置的“时钟设置”提供计时数字大小滑块（12–26，默认 18）、等比例示例与恢复默认按钮；拖动即时预览，停止调整或收起设置后自动保存。字号随外观配置导入导出，应用材质预设不改变字号。

闹钟默认只提醒一次，选择时间后明确显示今天或明天的具体时间；已过时间自动安排到次日，最多保存 20 个，可备注、编辑、关闭或删除。闹钟按当地日期时间触发，时区变化重新换算；夏令时缺失分钟映射到首个有效分钟，重复小时采用标准时偏移。通知提供停止和稍后 5 分钟，修改闹钟会使旧通知失效。

倒计时同时运行一个，提供 5／10／25／60 分钟预设，也能设置时分秒（1 秒至 99 小时 59 分 59 秒），用途可选。支持暂停、继续、取消，结束后可再计一次。运行时保存结束时间，暂停时保存精确剩余时间，不依赖逐秒累加；软件重启后恢复。铃声使用 Windows 闹钟通知，由系统音量、通知和勿扰规则控制，面板会提示通知不可用；自动验证使用静音通知。

锁屏或睡眠期间暂停发送，恢复后补提醒，每轮最多三条，已发送状态持久化以避免重复；通知未被系统接受时不误标为已提醒。退出前若有未结束的闹钟或计时会确认，退出或关机期间不能响铃；下次启动补发尚未发送的提醒。通知与待办共用一个注册实例，分别使用通知分组，不互相清理。退出停止时钟铃声，不删除记录。

时钟独立保存在 `%LOCALAPPDATA%\Liubai.Bar\clock.json`，使用原子替换与 `.bak` 备份，损坏时恢复备份，未知版本或两份损坏时停止写入。外观配置导入、恢复默认均不修改时钟数据。回归检查见 `tests/ClockChecks`；原生验证 `dist\Liubai.exe --verify-clock --data-dir <独立目录>` 覆盖标签、工具栏、暂停、面板收起、唤醒、通知动作与静音系统通知，可加 `--preview-clock` 暂留测试面板用于画面检查。

## 屏幕守护

设置左侧新增盾牌勾选图标，点击启停，也可在“屏幕守护”设置中启停。每次启动默认关闭；只持久化摄像头选择、提示方式和自定义文案，不保存开启状态。支持中央提示和全部屏幕黑色遮挡，按 Enter、Esc 或“解除”恢复，解除后冷却 30 秒。黑色遮挡期间暂时隐藏顶栏，保留原工作区，解除后恢复；提示仅在普通桌面提供辅助提醒。

右键盾牌可“暂停 10 分钟”或“立即恢复”。暂停保留本次会话的启用选择，并释放摄像头；到期以单次定时器恢复，无后台轮询。锁屏或睡眠不会提前结束手动暂停；暂停到期时如仍在锁屏，则等解锁再恢复。关闭守护或退出会清除暂停，不会在关闭后自动打开。修改触发等待时间时重新累计出现时长，保留现有提醒／冷却状态。

使用 Windows 本地 FaceTracker 检测额外人脸：画面中至少两张人脸连续出现达到所设等待时间才触发，等待时间可设置为 0.5～5 秒（默认 1.5 秒），断帧或单人画面重置等待。只统计人脸，不识别身份，无法确认注视方向或视野外的人。低光、侧脸、照片等可能影响结果。无权限、设备断开或 5 秒没有新帧时显示不可用状态，释放捕获资源，由用户重新开启。

所有显示器共用一个摄像头服务。共享只读采集不修改其他软件的摄像头格式；NV12 输出按比例限制在 320×240 以内，每次分析结束至少等待 500 ms，无并发推理、历史帧队列和实时画面 UI。提醒及冷却期间停止分析，关闭、锁屏、睡眠或退出时释放摄像头；唤醒后只恢复本次会话中用户已开启的检测。共享采集的底层摄像头帧率由设备及其他使用者决定，2 次/秒是本软件分析上限，实际总资源占用取决于驱动与硬件。

摄像头画面仅用于内存中的本地分析，不保存、不上传，不使用麦克风。设置独立保存在用户目录 `guard.json`，包含原子写入及备份。可先点击“测试提醒（不打开摄像头）”检查遮挡与解除效果。设置支持选择摄像头、切换提醒方式及最多 200 字自定义内容。

`tests/GuardChecks` 检查设置恢复、启动隐私、触发持续时间、断帧及冷却；`dist\Liubai.exe --verify-guard --data-dir <独立目录>` 使用模拟摄像头检查串行启停、锁屏释放、冷却停算、多屏遮挡和原生设置。增加 `--interactive-guard` 用真实 Enter 解除测试遮挡；增加 `--verify-guard-camera` 短暂调用真实摄像头，只生成性能和帧数报告，不保存画面。

## 收纳盒 · 中转站

中转站与 AI 助手展开为独立窗口后，可拖动标题文字及标题栏空白处移动整个窗口；右侧展开、固定和关闭按钮保留点击操作。收起为顶栏面板后不启用窗口拖动。

项目左侧显示 48 像素预览：图片与文件使用 Windows 缩略图，无预览时保留文件／类型图标。缩略图异步加载，内存缓存有上限，收起或刷新会取消旧请求；真实图片预览提取颜色作为卡片的淡色渐变背景，并适配深浅主题。右侧为统一白色细边框的“打开、复制、移除”图标；文件用默认应用打开，文件夹进入资源管理器，链接交给浏览器，文字可展开选择与查看全文。打开后记录仍保留。

把文件、文件夹、文字或 HTTP/HTTPS 链接拖向顶栏收纳盒，悬停 350 ms 展开中转站，松手存入；也可以直接放到图标上，或点击图标后拖入面板。成功存入后保持面板在前台，显示存入结果，点击外部再收起。拖离入口并放弃存入时自动收起。栏高不足 24 或顶栏隐藏时，也可用托盘右键“打开中转站”。

卡片上方内容可以直接拖到支持对应格式的目标软件，或点击“复制”再粘贴。所有拖放只允许复制操作；拖出后卡片仍保留，方便重复使用。链接可手动交给默认浏览器打开；不抓取网页或联网获取标题。每项右侧提供复制和垃圾桶图标按钮，悬停显示说明。右上角依次是展开、固定、关闭：普通面板点击外部或 Esc 收起；固定后保持展开。展开为可移动、调整大小的独立窗口，点击外部或打开其他功能不会收起，再次点击展开按钮停靠回顶栏。独立窗口中的固定按钮控制置顶，关闭收起时取消固定。

默认最多 200 项，可在“中转站设置”中改为 1～2000 项；调低上限保留已有记录，超出时暂停新增。重复路径、文字或链接自动去重；超过剩余容量时整批拒绝，保留已有记录。支持单项移除、确认清空。已有本地路径的文件仅保存原位置，不复制内容，不移动或删除原文件；原位置不可用或已失效时提示，并禁用本次卡片拖出和复制，重新打开会再检查。浏览器拖入的网址优先识别为链接，不受其附带的虚拟文件格式影响。没有本地路径的虚拟文件自动复制到数据目录 station-files；存入失败会回滚本次生成的附件。移除记录后已保存的附件仍留在本机，不自动删除。虚拟文件夹需先保存到本地。目标软件能接收哪些格式，取决于其自身拖放能力。

右上角依次提供清空（扫帚）、归档（向下入盒）、放大、固定和关闭图标；悬停提示操作名称，筛选时提示当前结果数量，无项目时禁用清空及归档。底部保留归档进度与取消入口。归档首次使用时选择目标目录，首次选择目标目录，之后记住位置，也可在设置中更改。归档会复制实际文件及完整文件夹，文字存为 UTF-8 TXT、链接存为 URL，并生成带收纳时间和 SHA256 校验信息的清单。确认窗口默认勾选“归档成功后移出中转站”，只移出成功复制且校验通过的对应记录；失败项保留，原文件不删除。取消时所有记录保留，已复制内容留在带“未完成”标记的目录。文件夹内的链接不会自动遍历，目标位于源文件夹内部时拒绝该项，避免递归复制。数量较多时每次展开 50 项。

记录独立保存在 `%LOCALAPPDATA%\Liubai.Bar\station.json`，重启后恢复，并使用原子替换和 `.bak` 备份。主文件损坏时恢复有效备份；两份损坏或数据版本不兼容时停止写入，不覆盖原文件。外观导入、恢复默认设置均不改动中转站数据。文字最多 20,000 字符；不监听或读取系统剪贴板，只有手动点击“复制”才写入。

数据回归见 `tests/StationChecks`；原生验证：`dist\Liubai.exe --verify-station --data-dir <独立目录>`，检查真实 Windows 数据包输入输出、浏览器多格式链接优先级、虚拟文件落盘与回滚、存入后前台确认、复制语义、固定置顶、独立窗口与重新停靠、外部收起、悬停放弃及面板互斥。可加 `--interactive-station` 在同一原生窗口的独立测试区做鼠标拖入和拖出；跨软件兼容性需在对应目标软件实测。自动验证只使用独立测试内容，不读写系统剪贴板；交互时主动点击“复制”则按正常功能写入。

## 待办与随手记

点击顶部对应图标打开面板；托盘右键菜单也可直接进入，栏高不足 24 像素或隐藏顶栏时仍可使用。同一时间只显示一个功能或设置面板；点击外部、按 Esc 或关闭按钮可收起，未提交的新任务作为草稿保存。编辑任务、选择所属弹窗时保持面板打开，先完成或取消编辑再切换入口。

- 待办：输入标题后回车或点击“添加待办”。日期、备注可选；“今天”包含逾期任务，“计划”列出未来日期，“全部待办”包含无日期的任务，“已完成”单独查看。支持标题与备注搜索、编辑日期和内容、完成或恢复，以及删除后撤销。
- 随手记：多行纯文本，停笔 400 ms 后自动保存；切换、收起及退出前也会核对输入框的最新内容。支持新建、历史记录搜索、置顶、复制和删除撤销。再次打开继续编辑上次记录。

待办与随手记共用右上角的细线保存图标，位于关闭按钮左边，点击立即保存待办草稿和随手记；保存过程中暂时禁用按钮，底部保留保存状态与时间。待办草稿仍需回车或点击“添加待办”才加入任务列表。
- 笔记转待办：保存最新内容后创建关联任务，可立即安排日期；保留原文，多次点击同一记录不会重复创建任务。
- 数据保护：内容保存在 `%LOCALAPPDATA%\Liubai.Bar\planner.json`，每次原子写入并保留上一份 `.bak`。原文件损坏时从有效备份恢复；两份均不可读或版本不兼容时停止写入，避免覆盖。数据独立于外观配置，恢复默认外观及导入外观配置不会清除任务或笔记。手动备份时请先退出软件，再复制 `planner.json` 与 `.bak`；本版尚不含独立数据导入导出界面。

列表每批展示 50 条，可加载更多；单条笔记／备注最多 20,000 字符，任务标题最多 200 字符。暂不包含重复任务及月历视图。

### 时间与提醒

新建或编辑待办时，可设置日期、24 小时时间和提醒方式：不提醒、准时，或提前 5／10／15／30 分钟、1 小时、1 天。只填写日期不会自动开启提醒；清除日期会同时清除时间和提醒。

提醒通过 Windows 原生通知发送，支持“完成”“10 分钟后提醒”“打开任务”。完成直接保存任务状态；稍后提醒只延后本次提醒，不修改任务原定日期与时间；打开任务进入对应任务的编辑面板，当前有编辑弹窗时会等弹窗结束再打开。已删除、已完成或已改期的旧通知不能再修改新任务。

提醒需要留白保持运行。锁屏、睡眠期间暂停发送，解锁、唤醒或重新启动后补发尚未发送的提醒；每轮最多处理三项。已发送状态保存在任务数据中，刷新和重启不会重复发送。修改时间或提前量会重新安排提醒，完成、删除、关闭提醒或改期时会撤掉旧通知。系统关闭通知时不会标记为已发送，面板会提示；请在 Windows 通知设置中开启留白通知，勿扰模式仍遵循系统规则。

任务数据已升级为版本 2，自动读取原来的版本 1；保存后请使用新版留白，旧版不会覆盖新格式。Windows 通知使用 Windows App SDK 自带能力，不另加通知库或后台服务。退出软件后不会继续计时或唤醒电脑。

回归检查：`dist\Liubai.exe --verify-planner --data-dir <独立目录>`，检查真实编辑器的草稿、自动保存、搜索、撤销及面板互斥。数据持久化、筛选、损坏恢复与并发写入检查位于 `tests/PlannerChecks`。

通知检查：`dist\Liubai.exe --verify-reminders --data-dir <独立目录>`，发送并自动清理一条测试通知；不会操作正式任务。提醒时间、操作幂等、旧通知失效、重启去重和写入失败重试也由 `tests/PlannerChecks` 覆盖。

## 日常设置、多屏与配置

展开设置顶部的“日常设置与配置”：

- 显示范围：所有屏幕或仅主屏。每屏按自身 DPI 计算物理高度，设置面板在打开它的屏幕定位。切换焦点到另一屏后，原屏继续跟随该屏最上层可见窗口，颜色不会跨屏串用。
- 暂停颜色跟随：保留当前外观、停止后台取色和窗口事件监听；恢复后重新识别。暂停选择会保存，暂停状态下重启从日常玻璃开始。托盘也提供快速切换。
- 开机启动：使用当前用户的 Windows 计划任务，登录后延迟 15 秒启动，显式指定程序工作目录，不请求管理员权限、不保存密码。默认关闭，导入配置不改变本机自启选项；已启用的旧 Run 项在正常启动时迁移，注册成功后移除旧项，避免重复启动。任务允许电池供电、没有驻留时长限制，异常退出后每分钟重试一次，最多 3 次。开关读取任务实际启用状态；系统中手动禁用任务后不会在每次运行时强制打开。启用后请保留完整的程序目录。
- 导入／导出：使用 JSON 文件，包含外观、高度、显示范围、暂停选择和个人预设。先校验版本、全部参数及预设，再原子替换；不支持的版本、损坏内容、超出 1 MB 的文件或写入失败不会替换当前配置。导入会替换现有个人预设列表，可先导出备份。
- 恢复默认设置：确认后恢复默认外观、36 像素高度、全部屏幕和自动跟随；保留个人预设以及开机启动选择。

设置底部“个人预设”可命名保存、应用或删除。预设保存日常材质、最大化／全屏外观、切换速度、动画和高度，不改变显示范围、暂停选择或开机启动。最多 30 个，同名保存会更新。打开系统文件选择器或确认窗口时，设置面板暂时保持打开，返回后恢复点击外部收起。

显示器连接、断开、分辨率和缩放变化后重新核对窗口与工作区；锁屏、睡眠期间暂停取色并清理动画，解锁／唤醒后重新连接材质和监听。壁纸、主题及 DWM 变化会刷新日常材质。

桌面回归：`dist\Liubai.exe --verify-desktop --data-dir <独立目录>`。检查实际连接屏幕的布局／DPI高度、显示范围切换、暂停后停止取色、隐藏与退出释放工作区，并通过模拟通知检查睡眠、锁屏、壁纸和显示变化的处理路径；不会实际改变系统缩放、壁纸或执行睡眠。结果为 `desktop-check.json`。多屏热插拔、混合缩放和真实睡眠仍需在对应硬件环境实测。

## 顶栏高度

设置中的“顶栏外观设置”提供“顶栏高度”滑块（1–120 个逻辑像素），默认 36，可一键恢复。调整会即时更新顶栏和 Windows 顶部预留工作区，停止操作后自动保存；高度独立于外观预设，跟随 Windows 显示缩放。停止调节后设置面板重新定位到顶栏下方。低于 24 时收起顶栏齿轮，避免图标被裁切，仍可从托盘打开设置。

## 最大化／全屏外观

设置提供独立开关和三种模式，默认启用“自动黑白”：

- 自动黑白：暗色窗口使用纯黑底、白图标；亮色窗口使用纯白底、黑图标。
- 自定义底色：选择色块或输入 HEX，图标按底色的黑白对比度自动选择。
- 跟随窗口颜色：提取窗口顶部的稳定代表色作为底色，图标自动配色。

每屏分别识别其最上层窗口的最大化或无边框全屏状态；窗口还原或回到桌面后恢复日常玻璃。设置面板和临时系统菜单保持上次稳定外观。窗口顶部取样会跳过被遮挡的点，通过主色聚类减少文字、图标干扰；取色不可用时保留上次稳定色。轻微色差与明暗临界区不会反复切换。

最大化场景由独立的窗口状态与几何模块判断，不依赖采样颜色：普通窗口、分屏及只是接近铺满工作区的窗口保持日常玻璃。只有确实覆盖工作区的最大化窗口或真正全屏才进入专用外观。取色独立校验横向覆盖：有效点至少覆盖采样网格的 70%，跨越足够列及左中右区域；主色还需达到 65% 支持并分布到至少 11/16 列；标签栏与内容区上下分层时，也可由至少两行各自横跨 11/16 列、左中右区域的一致颜色确认。局部露出的颜色不能放大成全栏主色。同一窗口短暂遮挡保留其已验证颜色；新窗口取色不可靠时先用日常玻璃，不能继承另一窗口的颜色。自定义底色只使用窗口状态，不进行屏幕取色。

前台切换、最小化和窗口尺寸事件立即唤醒后台检测，变化期间以 50–90 ms 间隔确认；窗口稳定后降低采样频率。原生事件不可用时保留轮询回退。颜色确认与最大化／还原的几何稳定等待并行，新事件使旧采样失效，避免过时颜色覆盖新窗口。仅在最大化／全屏时读取顶部小区域并缩为 96×16 的内存图像。设置关闭后停止检测并解除事件监听。此功能不修改 Windows 系统主题或其他软件配置。

“切换速度”提供灵敏、均衡、稳重，默认均衡。均衡档切换前台窗口的颜色确认时间为 120 ms，进入最大化的稳定确认时间为 220 ms，退出专用外观使用 80 ms 短确认，不等待整个还原动画结束；实际响应还取决于窗口动画、捕获耗时和采样间隔。同一窗口内部变色使用较长确认，减少动态内容干扰。

“过渡动画”提供标准（180 ms）、柔和（280 ms）、关闭，默认标准。变化时只捕获一次顶栏当前合成画面并淡出；临时图层不接收鼠标、不中断焦点。玻璃材质始终保持连接，最大化时用不透明表面覆盖，恢复窗口时直接露出已有材质，避免重新连接造成亮闪。图标仅改变自身主题，玻璃底层主题保持稳定。窗口变化通知只刷新检测，不提前移除正在淡出的遮罩；确认下一外观后从当前可见画面接续过渡。尺寸变化、隐藏或退出会清理动画；系统关闭动画时直接切换。过渡期间继续检测窗口状态，连续位置事件不重置一致状态的确认计时；最大化稳定后的轮询回退间隔不超过 250 ms。取样和过渡图像均仅在内存中使用，不写入文件、不上传。事件触发、稳定等待与旧画面淡出思路参考 [LumaBar](https://github.com/bin-art-666/LumaBar)，取样位置和 WinUI 内部过渡针对顶部栏独立实现。

验证运行：`dist\Liubai.exe --verify-expanded --data-dir <独立目录>`，会短暂显示纯色测试窗口，检查深浅取色、三种实际底色与图标对比度、真实过渡中间色、动画取消与焦点、窗口还原和无边框全屏，自动退出并生成 `expanded-check.json`。

## 自定义材质

设置中可先选择预设，再调节：

- 材质基底：轻薄玻璃 / 厚实亚克力 / 无基底。无基底关闭原生亚克力和模糊，只直接叠加染色及明暗遮罩，两项均为 0 时完全透明；图标和可选分隔线仍正常显示。旧配置默认保持原基底，个人预设、导入导出均包含该选项。
- 染色不透明度：0–100%，控制染色浓度。
- 明暗遮罩：0–100%，控制原生材质的亮度遮罩与背景遮蔽感。
- 自动配色或自定义颜色：关闭“染色跟随系统明暗”，展开颜色面板，可用预设色块、RGB 滑块或 HEX 色值。
- 顶栏底部分隔线：默认隐藏，可按需显示。顶栏与设置面板均移除外框描边，顶栏铺满屏幕边缘。

设置底部的“确定保存”按钮可立即写入全部设置，并显示保存时间；保存失败会明确提示。调节时直接更新现有材质控制器，停止操作 350 ms 后自动保存；收起设置、退出时也会保存待写入的调节。点击桌面或其他窗口时，设置面板会自动收起并保存待写入的调整；面板内部的下拉菜单与所属弹窗不会触发收起。点击关闭按钮或按 Esc 也可收起，再次从顶栏或托盘打开。选择预设会保留上次自定义参数，可从设置或托盘切回“自定义”。旧版只含 `Style` 的配置自动兼容，损坏或越界配置尝试从备份恢复。

交互参考 [LumaBar 外观编辑器](https://github.com/bin-art-666/LumaBar/blob/main/src/AppearanceEditor.cs) 的预设、独立染色、颜色和分隔线设置。留白使用 `DesktopAcrylicController`；它不提供独立的模糊半径，因此此处没有将染色或遮罩滑块标为模糊强度。

## 一键隐私

顶部锁形按钮支持 Ctrl 拖动排序；左键直接开启／恢复隐私模式，右键直接打开隐私保护设置。首次使用默认选择当前支持的摄像头与录音输入，之后保留用户选择（包括主动取消全部选择），不自动加入新设备。启动程序或打开设置不会更改设备状态。开启前停止屏幕守护并取消暂停计时；同一会话恢复成功后按原状态恢复守护，跨进程重启后不会自动开启守护摄像头。

设备操作通过临时提升权限的同一程序调用 Windows Configuration Manager，完成后退出，不安装常驻管理员服务。只识别 Camera、USB Video 旧式 Image 摄像头和 AudioEndpoint 中的录音端点，不禁用 MEDIA 声卡、USB 父设备、扬声器或网络。摄像头禁用可能影响 Windows Hello，录音输入禁用可能中断通话；录音端点禁用不能保证覆盖驱动提供的其他采集接口，也不等同于物理断电。

`privacy-options.json` 保存本机设备选择，不随外观导入导出；`privacy-state.json` 保存恢复记录。每次修改前落盘操作意图，修改后读回设备状态；仅恢复本次实际操作或中断时可能已操作的设备，原本关闭的保持关闭。部分失败、未连接、驱动拒绝均保留恢复记录供重试；取消授权不修改设备。退出程序不自动开启设备，重新启动后仍可恢复。恢复记录无法读取时停止自动操作并保留文件，可通过 Windows 设备管理器手动处理。禁用状态跨重启保留，删除程序前应先恢复。

锁内感叹号表示尚未核验或部分设备状态异常；展开分类并刷新列表可检查当前设备状态。新插入的设备不自动禁用，需要刷新选择。定位仅提供 Windows 设置入口，留白不会自动关闭定位，也不会把定位显示为已保护。

检查：`tests/PrivacyChecks` 覆盖原状态、持久化顺序、中断恢复、设备拔出、部分失败与禁止操作扬声器；`--enumerate` 仅执行本机设备的只读枚举。`--verify-privacy --data-dir <隔离目录>` 检查原生图标和设置页面，不申请权限、不修改真实设备。

## AI 快捷窗

顶部 AI 图标默认展开停靠在顶栏下方的玻璃面板，与中转站共用 PanelWindow 生命周期。右上角依次为展开／停靠、固定、收起：只有点击展开才进入可调整大小的独立窗口；未固定的停靠面板点击外部自动收起，固定后保持展开；独立窗口点击外部保持打开。收起、放大、停靠均复用同一个 WebView2，不重新加载对话。停靠面板默认 430×660 DIP；左边缘调整宽度（360～1000 DIP），上下边缘调整高度（360～1200 DIP），拖动时保持对侧边缘不动，松开后自动保存尺寸及上边缘位置。实际范围限制在屏幕工作区内，不覆盖顶栏。方向键可微调，Esc 取消本次拖动。独立窗口的位置和尺寸单独记忆，停靠尺寸按显示缩放换算，不重新加载对话。

通过 Edge WebView2 内核直接承载 AI 官网，不启动外部 Edge 应用窗口。默认 DeepSeek，可在面板、右键菜单或设置切换豆包、小艺、ChatGPT（https://chatgpt.com/）及自定义 HTTPS 网址；保留四个内置服务及当前自定义网址的页面，替换自定义网址时关闭旧的自定义页面。网页请求的附加窗口在面板内部显示，提供“返回 AI 对话”，避免弹出额外浏览器窗口，并保留原页面及其弹窗通信关系。

首次使用才创建网页控件，不随开机加载网页；收起或切换到后台的页面使用 WebView2 低内存目标，不强制挂起，以免打断生成。登录数据保存在 `%LOCALAPPDATA%\Liubai.Bar\AiWebProfiles`，与普通 Edge 及旧版外部窗口的 `AiEdgeProfiles` 分开；不删除或迁移旧登录数据，首次可能需要重新登录。退出留白会释放所有内嵌页面；未发送草稿能否恢复由网站决定。

`ai.json` 保存服务、固定和独立窗口位置，带原子写入与备份恢复；这些本机设置不随外观导入／导出迁移。留白不读取真实网站的对话，不注入修改网站的脚本，不自动发送剪贴板、截图或文件，不自动批准网页权限或忽略证书错误。外层玻璃样式保持统一，网页内容保留网站本身的界面。

`tests/AiChecks` 检查官网、自定义网址校验、配置与备份、导航边界、多屏位置约束。原生验证使用 `--verify-ai-panel --data-dir <隔离目录>`，只加载本地测试 HTML，检查真实 WebView2 草稿在收起、放大、停靠、服务切换及附加页面返回后是否保留，不登录或连接 AI 网站。

## 构建

需要 Windows 11 x64、.NET 10 SDK，首次构建需要联网还原 NuGet 依赖。可使用全局 SDK，或把便携 SDK 放入 `.tools\dotnet`。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

本地只保留这一个项目目录和 `dist\Liubai.exe` 正式运行入口。构建前先从托盘退出留白；构建使用固定的临时目录，成功替换后自动清理临时回滚副本及程序的 `bin/obj`，不累积 `previous-*` 版本。构建替换失败时恢复原运行目录。开机启动与快捷方式始终指向正式运行入口；已注册的留白登录任务会在正常启动后修正为当前路径并保留其启用/禁用状态，原本未启用时保持关闭。历史源码通过 GitHub 的提交记录回溯。

验证运行：`dist\Liubai.exe --verify-shell --data-dir <独立目录>`。自动检查托盘图标注册、工作区预留、隐藏/显示时工作区释放与恢复、三种材质创建及退出前工作区恢复，然后退出，结果保存为该目录的 `shell-check.json`。`--show-settings` 启动后打开设置供界面检查。

网络环境下若 NuGet 客户端无法连接，可先运行 `tools\FetchDependencies.ps1` 从官方 NuGet 下载并校验本地依赖源，再运行 `build.ps1 -Offline`。

## 后续功能面板

待办、随手记、AI、中转站、设置和时钟入口支持点击打开、再次点击同一入口收起；待办与随手记之间点击则切换页面。固定面板及独立窗口同样支持图标收起，保留内容与布局；确认框或文件选择等模态操作期间不响应入口开关。点击这些入口时不会先被外部点击检测关闭再重新打开。

面板展开时，对应图标保留淡色圆角底色，收起后恢复透明；待办与随手记只高亮当前页面。高亮随明暗配色切换，仅在面板状态或外观变化时更新，不增加定时轮询。

新增临时功能面板统一继承 `PanelWindow`：使用 `InitializePanel` 接入内容、`ShowPanel` 显示，收起前的保存或清理放在 `OnHiding`。基类统一处理外部焦点、所属弹窗保护、Esc、关闭与重复打开；常驻的顶栏不继承此基类。使用窗口激活通知，并仅在面板打开期间监听鼠标按下以覆盖不转移焦点的桌面区域；面板收起时立即解除监听，不轮询桌面。拖动滑块时不会因指针移出面板而收起。

开机启动诊断：任务名为 `Liubai-<当前用户 SID>`，以该用户的交互桌面运行。登录任务传入 `--startup`；`%LOCALAPPDATA%\Liubai.Bar\startup.log` 记录 launch、ready 或失败类型，最多约 64 KB。任务调度器提供上次运行结果；这里的 ready 表示桌面栏已完成初始化，真实重启后的触发仍需在下次登录确认。自启定义回归检查见 `tests/StartupChecks`。

开发环境注意：带打包身份的宿主（例如 Codex）可能让子进程的用户目录和注册表写入重定向到宿主缓存，形成手动运行与登录启动的数据差异。正式运行优先通过登录任务或资源管理器启动。迁移开发期数据时先退出留白，保留原数据并逐文件校验，不能覆盖已有的不同内容。

中转站面板支持四边拖动：左右边缘调整宽度，上下边缘调整高度，保持对侧边缘不动，松开自动保存，Esc 取消本次调整。停靠尺寸和偏移按 DIP 保存，限制在当前屏幕工作区内；独立窗口位置和尺寸单独记忆。窗口布局保存在 station-window.json，与项目文件分开，调整尺寸不重新生成卡片、不改写项目或原文件。原生隔离检查：--verify-station-size --data-dir <独立目录>。

## 中转站分类与查找

展开后的独立窗口提供全部、图片、文件（不含图片）、文件夹、文字、链接六类；宽窗口显示左侧分类菜单，窄窗口改为分类下拉框。分类数量应用当前搜索和时间条件。搜索匹配文件名、文字、链接地址及标题，不扫描文件内容或文件夹内部。

时间筛选提供全部时间、今天、最近 7 天（含今天及之前六天）、最近 30 天。日期按本地时区和存入时间计算，最新项目在前；独立窗口按今天、昨天、更早分组，卡片显示存入时间并提供完整日期提示。每分钟仅在面板打开时检查跨日，跨日后更新分组与结果。

分类、时间和关键词保存在 station-window.json，展开后恢复；停靠回顶栏时显示全部项目，保留展开时的条件供下次展开继续。清空与归档使用当前匹配项目的完整快照（含尚未分页显示的匹配项目），按钮和确认框显示范围及数量；取消不修改记录，确认后仅移除该快照中未变化的记录，不波及其他分类或确认后新增的记录。归档仍逐项复制及校验成功后才按选项移出。

在筛选状态下拖入其他类型也会正常保存，并提供“查看全部”，不会为了显示新项目而自动切换分类。`--verify-station-browser --data-dir <隔离目录>` 检查原生分类、搜索、日期组合、确认取消、筛选外拖入及宽窄布局；不会读取真实用户项目或执行真实清空／归档。

## 工作流交互

- 文字或链接拖到待办图标，会直接添加为任务，保留尚未提交的草稿；图片或文字拖到随手记图标，会新建图文记录。图片转为最大边 2048 像素的本机 PNG 副本，移动原图不影响记录。每次最多 12 项、单张输入最多 32 MB。
- 中转站面板中的“工作现场”可以创建、切换和重命名分组，并从已有资料、待办、笔记中选择加入。选中现场后新内容自动关联；选择“未分组”停止自动关联。工作现场保存文件位置、链接和文字的独立快照，清空中转站不会清掉现场资料；原文件移动或删除后会提示不可用。移除分组只移除引用，原文件和原记录均保留。
- 待办卡片右侧的时钟按钮打开“专注与接续”，默认 25 分钟，可调整为 1～240 分钟；复用现有倒计时，不覆盖活动计时。顶栏细线显示进度，任务短标题可点击打开暂停、继续和接续记录。结束不会自动完成待办，提醒仍由现有时钟提供。
- 整屏截图后出现同材质的小预览，可“存入中转站”“提取文字”“记一笔”；10 秒无操作自动收起，鼠标停留或操作期间保留。文字识别使用 Windows 本机 OCR，需要对应系统语言包，不上传识别。关闭截图文件保存时，预览只在内存中保留；明确存入中转站或记一笔时才保存相应附件。
- 按住待办、随手记或时钟图标约 650 ms，显示只读预览，松开收起；普通点击仍打开完整面板，Ctrl 拖动仍用于排序。预览不改变原面板的编辑内容或保存状态。
- 拖向 AI 图标的内容进入本机确认区，确认前不交给网页。点击“确认交给…”后，文件可能立即由网站上传，文字追加到当前输入框；留白不自动点击网页发送按钮。服务改变、页面未就绪或附件入口不明确时停止并保留暂存内容。不同 AI 网站的上传控件可能变化，不能确认唯一附件入口时请使用网页自己的附件按钮。网站自带的附件操作仍遵循网站行为。

中转站中的文件、图片、文字和链接也可直接拖到 AI 图标，松手后进入同一确认区，中转站原记录和原文件继续保留。已有暂存时提供“追加／替换／取消”；合并上限为 12 个文件、20000 字。不同服务的暂存不能直接追加，取消或接收失败不会覆盖原暂存。文件夹暂不接收。拖动期间保持源面板展开，但不阻止 AI 接收；真正的确认框与文件选择仍受模态保护。

工作现场、图片附件映射和专注接续记录保存于用户数据目录中的 workspaces.json，使用原子替换和 .bak 备份；原有 planner.json、station.json 和 clock.json 格式保持兼容。图片保存在 note-images，移除笔记或分组不自动删除本机附件。原生隔离验证：`--verify-workflow --data-dir <独立目录>`，AI 测试只使用本机 HTML，不连接 AI 网站；存储回归见 tests/WorkChecks。
